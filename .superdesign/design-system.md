# FVS Management Dashboard Design Direction

The existing frontend is a practical school-management tool with a restrained emerald and slate palette, Tailwind utility styling, Lucide icons, white surfaces, and a pale green page canvas. Preserve the French product language, role-aware navigation, operational density, and clear form affordances.

For the proposed redesign, keep the existing identity but make the first screen a true role-based cockpit: show the current establishment and school year, surface a small set of actionable metrics, prioritize the role's main workflow, and keep secondary configuration in navigation. Use compact data-dense panels rather than marketing cards. Maintain responsive desktop sidebar and mobile navigation patterns.

Avoid changing business capabilities or inventing data. Reuse current labels and concepts: établissement, année scolaire, classes, élèves, inscriptions, frais, caisse, sécurité. Use Lucide icons and real role names. No new external images are required.
